Why don't color swatches show?

Swatches need the product's color option connected to the Color category metafield. In your Shopify admin, choose the product's Category, then under Category metafields click Color and choose Connect to option. Some categories have no Color metafield; pick a nearby category that has one.

Then check Theme settings → Product cards → Show color swatches and, on the product page, Variant picker → Show swatches. Cards show swatches for an option with at least two values. See Variant images and swatches.

How do I add filters?

Filters come from Shopify's Search & Discovery app. Add them in the app, including option filters such as Size and Color and swatch filters, then check Show filters in the Collection and Search sections. See Filters.

Why doesn't the image change when a swatch is picked?

Card swatches and quick view need an image attached to each variant. Add the images to the product, then open each variant in your Shopify admin and pick its image. See Variant images and swatches.

How do I set up the mega menu and level 3 links?

In the theme editor, click Header and set Menu style to Mega menu. Then nest your menu in Content → Menus: level 2 links with links under them become columns, and their level 3 links hang under them as tags.

For a level 3 link that shows part of a collection, add a collection link and use Filter collection with tags; the products need that tag. Product type filters need the Search & Discovery app. Tag-filtered links show no product count. See Menus.

Why doesn't the country or language selector show?

Each selector shows only when there is more than one choice: more than one country or region in Settings → Markets, or more than one published language in Settings → Languages. Also check Show country or region selector and Show language selector in the Footer. See Markets.

Why doesn't Follow on Shop show?

The button shows only when Shop Pay is turned on in Settings → Payments and the Shop sales channel is installed, and Show Follow on Shop is checked in the Footer. See Follow on Shop.

Should I use the cart drawer or the cart page?

Both work the same way. The drawer keeps customers on the page they're shopping; the page gives the cart its own address. Choose in Theme settings → Cart → Cart type. See Cart and Cart drawer and cart page.

Where do back in stock requests go?

With Show back in stock form on in the Buy buttons block, sold out variants show a Notify me button. Requests arrive as contact form emails with the product and variant. Customers aren't alerted automatically, so reply to them yourself when the product is back. The form isn't shown in quick view. See Buy buttons.

How do I show a different size chart or tab on each product?

Connect the block's Content to a product metafield with dynamic sources. This works for the Size chart block, the custom tabs of the Product label block and the Collapsible row block. For the size chart, Option name must match a product option (capital letters don't matter), and a picked Page wins over the content. See Size chart and Product label.

How do I offer a discount code in the popup?

Create the code in Discounts in your Shopify admin first. Then type it in the Discount code setting of the Promo popup. It's shown only after a successful signup. See Promo popup.

How do I set up gift wrap?

Create a gift wrap product, make it available on the Online Store sales channel, hide it from search with the seo.hidden metafield set to 1, and pick it in Theme settings → Cart → Gift wrap product. Gift wrap left alone in the cart is removed automatically. See Gift wrap.

How do I update Morph?

When an update is available, Shopify shows it in Online Store → Themes. Duplicate your theme first so you have a backup. Updating adds the new version to your theme library with your theme editor settings and content carried over. Changes made directly in the code are not carried over. Check the new version, then publish it. See the Changelog.

How do I translate my store?

Add languages in Settings → Languages, then translate your content with Shopify's Translate & Adapt app. To change the theme's own texts in your default language, such as button labels, go to Online Store → Themes, click the … (actions) button and choose Edit default theme content.

How do discount codes work?

Create discounts in Discounts in your Shopify admin. Customers enter discount codes at checkout. Discounts that apply to the whole order are listed in the totals of the cart drawer and cart page.

Can I edit the theme code?

You can, but we can't support code changes. Duplicate the theme first so you can go back, and keep in mind that code changes aren't carried over when you update. For custom work, hire a Shopify Partner. See the Support policy.
