Support policy

What our support for Morph covers, how quickly we reply and how theme updates work.

What support covers

  • Setting up the theme: installing, customizing and publishing Morph.
  • Questions about the theme settings, sections and blocks.
  • Bugs in the theme: something in Morph that doesn't work as these docs describe.

What support doesn't cover

  • Custom code, including changes to the theme's code and code added with Custom Liquid.
  • Third-party apps. Contact the app's developer for help with an app.
  • Design work, such as creating images, logos or custom layouts.
  • Store setup outside the theme, such as products, payments, shipping, taxes, domains and markets.
  • Coding tutorials. We can't teach Liquid, HTML, CSS or JavaScript.

For custom work, hire a Shopify Partner.

Response time

We reply within 2 business days. To help us answer in one reply, include the details listed on the Support page.

Theme updates

  • Updates are released through the Shopify Theme Store. Shopify shows them in Online Store → Themes.
  • Duplicate your theme before big changes or an update, so you always have a backup.
  • Every update is described in the Changelog.
